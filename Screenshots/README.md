# Screenshots Folder

## 📸 Required Screenshots

Place all execution screenshots in this folder.

### Screenshot Naming Convention:
- `01_main_menu.png` - Main menu display
- `02_create_request.png` - Creating a new request
- `03_queue_display.png` - Displaying queue contents
- `04_agent_list.png` - Showing all agents
- `05_process_request.png` - Processing a request
- `06_escalation.png` - Escalating a request
- `07_bst_display.png` - BST inorder traversal
- `08_search_result.png` - Search operation result
- `09_sort_result.png` - Sorting operation result
- `10_statistics.png` - Statistics display
- `11_empty_stack_error.png` - Error handling (empty stack)
- `12_full_queue_error.png` - Error handling (full queue)
- `13_invalid_input.png` - Input validation
- `14_integration_test.png` - Integration test result

### What to Capture:
1. **Normal Operations**: Show each feature working correctly
2. **Edge Cases**: Show error handling (empty, full, invalid)
3. **Testing Results**: Show test outputs
4. **Data Display**: Show formatted output of each structure

### Tips:
- Use clear, readable font size
- Include relevant console output
- Show both input and output
- Annotate if needed (add arrows, highlights)
- Save in PNG or JPG format

### For Report:
Select the best screenshots to include in your project report PDF.
